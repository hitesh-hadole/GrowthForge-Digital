# GrowthForge Digital — Astro Starter

Premium performance-marketing agency website starter built with Astro.

## Run locally

1. Install Node.js (LTS).
2. Open this folder in VS Code.
3. Run:

```bash
npm install
npm run dev
```

4. Open the local URL Astro gives you.

## Build for production

```bash
npm run build
```

The generated site is in `dist/`.

## Before GitHub Pages deployment

Edit `astro.config.mjs`:

- `site`: your GitHub Pages URL.
- `base`: your repository name if deploying to `username.github.io/repository-name`.

If using a custom domain later, update `site` and add your domain/CNAME setup.
